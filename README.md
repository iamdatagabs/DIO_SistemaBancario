# Sistema Bancário em Python — Desafio DIO (arquivo histórico)

Implementação educacional do desafio de sistema bancário desenvolvido durante um bootcamp da Digital Innovation One (DIO).

O exercício trabalha modularização de operações de depósito, saque e extrato, além do cadastro de clientes e contas correntes.

## Contexto atual
Este repositório preserva a implementação original do desafio. Uma releitura posterior, com escopo full-stack, API REST, persistência local e dashboard de inteligência de mercado, está no projeto **Nexus Banking**:

- **Projeto atualizado:** https://github.com/iamdatagabs/Sistema-Bancario-Python
- **Dashboard:** https://iamdatagabs.github.io/Sistema-Bancario-Python/

O Nexus Banking é um projeto educacional e não movimenta dinheiro real nem oferece recomendações de investimento.
